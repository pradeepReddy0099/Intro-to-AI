# Local, Deterministic Data Analysis Agent for Tabular Data

A local data analysis agent for a single tabular dataset (CSV or Excel). It runs a
fixed six-stage pipeline — **profile → clean → analyze → visualize → predict →
report** — entirely on your machine. It uses **no generative model, no external
LLM service, and no network calls**. Every explanation in the report is a fixed
template filled in from statistics the pipeline actually computed, and every run
saves its configuration and transformation log so the result is reproducible.

Implements the revised project proposal: *Local, Deterministic Data Analysis Agent
for Tabular Data*.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Example commands

Full report, no question (prediction skipped — no target given):

```bash
python -m agent analyze data/sample_sales.csv --out output/full
```

Ask a question and predict churn:

```bash
python -m agent analyze data/sample_sales.csv \
  --question "predict churn" \
  --target churn \
  --out output/churn
```

Ask about a trend or a relationship:

```bash
python -m agent analyze data/sample_sales.csv --question "any trends over time?" --out output/trend
python -m agent analyze data/sample_sales.csv --question "what drives revenue?" --out output/drivers
```

Each run writes `report.html`, `report.md`, `config.json`,
`transformation_log.json`, `profile.json`, and chart PNGs under `charts/` in the
output directory.

## Using it as a library

```python
from agent import run_pipeline

results = run_pipeline("data/sample_sales.csv", question="predict churn", target="churn", out_dir="output/churn")
print(results["status"])
print(results["prediction"]["best_model"])
```

## Module map

| Module | What it does |
|---|---|
| `agent/config.py` | Versioned configuration (seed, split, CV folds, limits); saved with every run. |
| `agent/guardrails.py` | Input validation, assumption checks, and explicit refusals (`RefusalError`). |
| `agent/io_utils.py` | CSV / Excel loading. |
| `agent/profiling.py` | Column types, missing values, duplicates, basic stats. |
| `agent/cleaning.py` | Duplicate removal, whitespace trimming, spelling unification, type coercion, missing-value filling — every step logged. |
| `agent/analysis.py` | Descriptive stats, correlations, group comparisons, trends over time. |
| `agent/visualization.py` | Rule-based charts (histograms, bars, correlation heatmap, trend lines) saved as PNG. |
| `agent/prediction.py` | Bounded AutoML-style model selection with scikit-learn + cross-validation, fixed seeds. Runs only when a target is given. |
| `agent/questions.py` | Rule/template-based question router (summary, compare, correlation, trend, predict). |
| `agent/reporting.py` | HTML + Markdown report generation; template explanations from computed values only. |
| `agent/pipeline.py` | Orchestrates the six stages; turns guardrail failures into refusal reports. |
| `agent/__main__.py` | CLI: `python -m agent analyze <file> [--question ...] [--target ...] --out <dir>` |

## Design notes

- **Determinism:** fixed random seeds, a pinned train/test split, fixed CV folds, and
  no timestamps in reports — re-running the same file with the same settings
  reproduces the same report.
- **Guardrails:** the agent refuses (with a plain-language reason) when the file is
  missing/unsupported/empty, when prediction has too few rows, a constant target,
  or classes with too few examples, and when a question names no target for
  prediction. It never returns an improvised result.
- **Privacy:** nothing leaves the machine. There are no API calls and no model
  downloads; the sample dataset is synthetic.

## Sample data

`data/sample_sales.csv` is synthetic (generated by `data/generate_sample.py` with
a fixed seed). It contains 242 rows of fake orders with a few missing values,
